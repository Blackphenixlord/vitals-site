# VITALS — website, brochure and tri-fold board

Outreach materials for **VITALS**, Team TETHER's NASA HUNCH 2026–27 entry
(Software & Technology: Medical Diagnostic System with ML & AI).

| What | Where |
|---|---|
| Website | `index.html` — live at https://blackphenixlord.github.io/vitals-site/ |
| Brochure (one Letter sheet, folds into 3) | `brochure/VITALS-brochure.pdf` — print double-sided, flip on short edge |
| Tri-fold display board (36 × 48 in) | `trifold-board/VITALS-trifold-board.pdf` — left 12 in · center 24 in · right 12 in |

The brochure and the board carry a QR code to the website.
Screenshots in `img/` are of the real astronaut screen; the answer shown is the demo case
(flight day 63, kidney stone).

The code is in https://github.com/Blackphenixlord/lunar-medical-diagnostic.

Not affiliated with or endorsed by NASA. VITALS is decision support, not a diagnosis, and not a medical device.
